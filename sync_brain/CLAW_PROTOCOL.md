# CLAW_PROTOCOL.md: 執行之手運作協定 (Execution Claw)
**版本**: 1.0 (Aligning with OpenClaw Core Brain)

> 「執行之手」(The Claw) 的唯一使命，是將「核心大腦」(OpenClaw) 的戰略意圖，完美轉化為物理現實與數位邏輯。

## 🛠️ 執行觸發規則 (Trigger Rules)

### 1. 網頁解讀 (Web Interpretation)
*   **觸發點**: 當 OpenClaw 標記某 URL 為「品牌靈魂素材」或「競爭對手戰略」時。
*   **執行模式**: 深入解讀頁面的視覺語義、商業邏輯，並直接同步至 `BRAND_CORE.md` 的參考庫。

### 2. 報告整理 (Report Synthesis)
*   **觸發點**: 每週日 24:00 (自動) 或當專案元數據發生「重大現實與數據落差」時。
*   **執行模式**: 反向審核日誌中的「非邏輯觀察」，生成「主權推進報告」。

### 3. 主動提案 (Proactive Opinions)
*   **觸發點**: 當「工程進度」與「主權目標」發生衝突時（例如：架構太完美導致產出太慢）。
*   **執行模式**: 發出警告，並提出「靈魂升級方案」。

## 🔗 與大腦 (OpenClaw) 的通訊
*   所有執行的錯誤日誌 (Error Logs) 必須首先回傳至 OpenClaw 進行戰略判斷。
*   Claw 不得在未經 OpenClaw 戰略校準的情況下，擅自修改 `NAVAL_PROTOCOL.md`。
