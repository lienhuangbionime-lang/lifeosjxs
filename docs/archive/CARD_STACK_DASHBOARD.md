# 卡片堆疊式 Dashboard + 浮動 AI 助手

## ✨ 最新更新

根據您的反饋，我們將 AI 功能從卡片中分離出來，改為**浮動助手按鈕**，讓您可以隨時方便地開啟詢問！

## 🎴 4 張數據卡片

現在只保留核心數據卡片，專注於數據展示：

1. **Overview** (紫色) - 總覽統計和趨勢
2. **Flow State** (綠色) - 心情狀態分析
3. **Deep Work** (粉色) - 生產力追蹤
4. **Neural Tags** (紫羅蘭) - 標籤雲

## 🤖 浮動 AI 助手

### 設計理念
- **獨立於卡片**：AI 不再是卡片之一，而是全局可用的助手
- **隨時可用**：無論在哪張卡片，都能快速開啟 AI 對話
- **不干擾視圖**：浮動按鈕不會遮擋主要內容

### 位置和交互
- **浮動按鈕**：位於右下角，固定位置
- **一鍵開啟**：點擊按鈕即可展開對話面板
- **快速關閉**：再次點擊或點擊 X 按鈕關閉

### 功能特點
- ✅ **實時對話**：與 Cortex AI 進行流式對話
- ✅ **文件上傳**：支持上傳 PDF、TXT、MD 文件
- ✅ **Markdown 渲染**：AI 回覆支持格式化顯示
- ✅ **狀態顯示**：顯示 AI 模型和剩餘配額

## 📱 使用方式

### 查看數據卡片
1. **滑動** - 在卡片上左右滑動
2. **箭頭** - 點擊左右箭頭按鈕
3. **圓點** - 點擊底部的分頁指示器

### 使用 AI 助手
1. 點擊右下角的**聊天圖標**按鈕
2. 在對話框中輸入您的問題
3. 按 Enter 或點擊發送按鈕
4. AI 會實時回覆您的問題

### AI 助手功能
- **詢問數據洞察**：「分析我這個月的心情趨勢」
- **獲取建議**：「如何提高我的深度工作時間？」
- **上傳文件**：點擊迴紋針圖標上傳文件讓 AI 分析
- **查看歷史**：所有對話都會保留在當前會話中

## 🎨 視覺設計

## 🚀 使用場景

### 數據分析場景
1. 查看 **Overview 卡片** 了解整體情況

## 🔍 注意事項

1. **AI 按鈕位置**：固定在右下角，不會隨卡片滑動移動
2. **對話持久性**：當前會話的對話會保留，刷新頁面後清空
3. **文件上傳**：支持 PDF、TXT、MD 格式
4. **API 連接**：需要確保後端 API 運行在 `http://localhost:8000`

## 🚀 快速啟動

```bash
# 啟動前端
cd frontend-body
npm run dev

# 啟動後端（另一個終端）
cd backend-cortex
python -m uvicorn main:app --reload --port 8000
```

訪問 `http://localhost:3000`，點擊底部 Dock 的 **Home 圖標**，即可體驗新的卡片式 Dashboard 和浮動 AI 助手！
