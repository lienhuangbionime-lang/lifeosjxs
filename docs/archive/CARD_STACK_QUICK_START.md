# 卡片堆疊式 Dashboard + 浮動 AI 助手 - 快速指南

## ✨ 新功能亮點

HOME 頁面現在使用**卡片堆疊式設計** + **浮動 AI 助手**！

## 🎴 4 張數據卡片

1. **Overview** (紫色) - 總覽統計和趨勢
2. **Flow State** (綠色) - 心情狀態分析
3. **Deep Work** (粉色) - 生產力追蹤
4. **Neural Tags** (紫羅蘭) - 標籤雲

## 🤖 浮動 AI 助手

**位置**：右下角浮動按鈕  
**功能**：隨時開啟與 Cortex AI 對話  
**特點**：不干擾數據查看，全局可用

## 📱 如何使用

### 查看數據卡片
1. **滑動** - 在卡片上左右滑動
2. **箭頭** - 點擊左右箭頭按鈕
3. **圓點** - 點擊底部的分頁指示器

### 使用 AI 助手
1. 點擊右下角的**聊天圖標**
2. 輸入問題並發送
3. AI 實時回覆
4. 再次點擊關閉對話框

## 💡 使用技巧

### 數據分析
- 查看卡片了解數據
- 開啟 AI 詢問洞察
- 獲取個性化建議

### AI 提問示例
- 「分析我這個月的心情趨勢」
- 「如何提高深度工作時間？」
- 「這些標籤反映了什麼模式？」

### 文件上傳
- 點擊迴紋針圖標
- 上傳 PDF、TXT、MD 文件
- AI 會分析文件內容

## 🚀 快速啟動

```bash
# 前端
cd frontend-body
npm run dev

# 後端（另一個終端）
cd backend-cortex
python -m uvicorn main:app --reload --port 8000
```

訪問 `http://localhost:3000`，點擊底部 Dock 的 **Home 圖標**！
