# LifeOS v3.1 - 使用手冊
**給日記記錄者的完整指南**

## 🎯 LifeOS 是什麼？

### 不只是日記本
LifeOS 是你的**第二大腦**和**智能顧問**。

你可以：
- 📝 記錄每天的想法、決策、心情
- 📂 管理所有專案（含股票研究）
- 💬 **問系統任何問題**，獲得智能回答
- 🔍 自動找出關聯、模式、建議

### 核心理念
```
不是「記錄過去」
而是「幫助未來」

系統會自動釐清你的問題
讓你專注發展新專案
```

## 🚀 快速開始

### 1. 記錄日記
```
1. 點擊底部 Dock 的 Home 圖標
2. 選擇「Capture」標籤
3. 輸入今天的內容
4. 系統會自動：
   - 分析你的心情、專注度、能量
   - 提取關鍵決策
   - 建立知識連結
```

### 2. 管理專案
```
1. 點擊「Project」標籤
2. 創建新專案（軟體、股票、研究都可以）
3. 添加任務和進度
4. 系統會自動追蹤時間和狀態
```

### 3. 問系統問題
```
1. 點擊右下角的 AI 助手按鈕 🤖
2. 輸入你的問題
3. 獲得智能回答和建議
```

## 💬 如何問問題

### 三大使用場景

#### 1. 看關聯性問系統
**你可以問**：
- 「這個專案和我之前做的有什麼關聯？」
- 「我在類似情況下做過什麼決策？」
- 「這個問題我之前遇過嗎？解決方案是什麼？」

**系統會回答**：
- 自動找出相關專案
- 提取過去的決策模式
- 顯示解決方案和結果

#### 2. 看專案問系統
**你可以問**：
- 「這個專案目前的狀態如何？」
- 「還有哪些待辦事項？」
- 「類似專案我花了多少時間？」
- 「TSMC 股票的研究進度？」（股票也是專案）

**系統會回答**：
- 即時專案狀態
- 自動整理待辦清單
- 時間估算和預測
- 投資研究摘要

#### 3. 看日記問系統
**你可以問**：
- 「那天我為什麼做這個決定？」
- 「我的心情趨勢和專案進度有關聯嗎？」
- 「我在壓力大的時候通常做什麼？」

**系統會回答**：
- 決策脈絡還原
- 自動關聯分析
- 行為模式識別

## 📊 Dashboard 使用

### 卡片堆疊式設計
左右滑動查看不同數據：

#### 1. Overview 卡片（紫色）
- 總條目數
- 平均心情
- 深度工作時數
- 月度趨勢圖

#### 2. Flow State 卡片（綠色）
- 心情狀態分析
- 詳細曲線圖

#### 3. Deep Work 卡片（粉色）
- 生產力追蹤
- 深度工作時間柱狀圖

#### 4. Neural Tags 卡片（紫羅蘭）
- 標籤雲
- 最常用的 12 個標籤

### 導航方式
- **滑動**：在卡片上左右滑動
- **箭頭**：點擊左右箭頭按鈕
- **圓點**：點擊底部的分頁指示器

## 🤖 AI 助手使用

### 開啟對話
1. 點擊右下角的**聊天圖標**按鈕
2. 對話框會彈出

### 提問技巧
```
✅ 好的問題：
「這個專案和 LifeOS v2.0 有什麼關聯？」
「我上週的心情趨勢如何？」
「TSMC 股票研究的最新進展？」

❌ 模糊的問題：
「這個怎麼樣？」（系統會主動問你指的是什麼）
「幫我看看」（系統會引導你明確需求）
```

### 上傳文件
1. 點擊迴紋針圖標
2. 上傳 PDF、TXT、MD 文件
3. AI 會分析文件內容並回答相關問題

### 關閉對話
再次點擊聊天圖標或點擊 X 按鈕

## 📝 日記記錄技巧

### 基本格式
```markdown
# 2026-02-10

今天完成了 LifeOS v3.1 的 Context Engineering 系統。

## 決策
- 決定使用 Question-Driven Architecture
- 原因：用戶需要的是問答，不是記錄

## 標籤
#lifeos #architecture #productivity
```

- ✅ 評估專注度（0-10 分）
- ✅ 評估能量（0-10 分）
- ✅ 提取決策記錄
- ✅ 識別標籤
- ✅ 建立專案關聯

## 📂 專案管理

### 創建專案
```
1. 點擊「Project」標籤
2. 點擊「+ 創建專案」
3. 填寫：
   - 專案名稱
   - 類型（軟體/股票/研究/個人）
   - 描述
   - 目標
```

### 股票專案範例
```
專案名稱：TSMC 股票研究
類型：stock
描述：研究台積電的投資價值
目標：
- 分析財報
- 研究產業趨勢
- 決定買入價格
```

### 添加任務
```
1. 進入專案
2. 點擊「+ 添加任務」
3. 填寫任務內容
4. 設定優先級和截止日期
```

## 💡 使用技巧

### 1. 每天記錄
```
建議：
- 早上記錄計劃
- 晚上記錄總結
- 隨時記錄重要決策
```

### 2. 使用標籤
```
好的標籤：
#coding #productivity #health #finance

避免：
#今天 #記錄 #日記（太通用）
```

### 3. 記錄決策
```
格式：
## 決策：[決策內容]
原因：[為什麼這樣決定]
預期結果：[期望達成什麼]

未來可以問：
「我上次做類似決策時的結果如何？」
```

### 4. 專案分類
```
軟體專案：LifeOS v3.1
股票專案：TSMC 研究
研究專案：AI Context Engineering
個人專案：健身計劃
```

## 🎯 常見問題

### Q: 如何刪除日記？
A: 長按日記卡片 → 選擇「刪除」

### Q: 如何導出數據？
A: 設定 → 數據導出 → 選擇格式（JSON/Markdown）

### Q: AI 助手不理解我的問題怎麼辦？
A: 系統會主動問你澄清問題，跟著引導回答即可

### Q: 如何備份數據？
A: 數據自動備份到雲端（Supabase），也可以手動導出

### Q: 可以離線使用嗎？
A: 可以離線記錄，連網後自動同步

### 數據儲存
